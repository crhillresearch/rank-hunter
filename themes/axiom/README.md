# Axiom

Axiom is Rank Hunter's research-dashboard theme with coordinated **Light** and
**Dark** appearances inside one theme package.

Light remains the default: a soft gray canvas, crisp white cards, cobalt-blue
actions, and restrained semantic status colors. Dark keeps the same hierarchy
and semantic colors on deep navy surfaces with high-contrast research text.

The appearance switch is presentation-only. Axiom uses Rank Hunter's stable
`rh-*` semantic hooks and appearance-token contract; it does not own
scientific behavior, navigation, or database semantics.
