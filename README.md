# Rank Hunter v0.10.x — Development

This is the active development branch for Rank Hunter v0.10.x.

This branch is experimental and may change frequently.
Features may be added, modified, or removed without notice.

## Install EXPERIMENTAL Development Release

```
git clone --branch dev/0.10.x --single-branch --recurse-submodules \
  https://github.com/crhillresearch/rank-hunter.git
cd rank-hunter
bash install.sh
bash scripts/run-ui.sh
```

## Major Changes
- Major UI redesign makes progress and proven ranks easier to see.
- One Search page for family, torsion, candidate-pool, curve, and general searches.
- AI Hunt can plan and run bounded Pipeline rounds, review results, and choose what to try next. Rank claims still require exact checks.
- A compact Tools workbench brings proof, point, and geometry tools together, including twists, isogenies, sections, base changes, and pencils.
- Casebook and Rank Lab help researchers track curves, keep notes, certify points, and plan the next search.
- New Pipeline presets and modules add Mestre–Nagao scoring, REA research, lattice searches, and genus-two Jacobian support.
