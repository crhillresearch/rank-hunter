# Legacy Analysis pages

These files are preserved snapshots of the pre-cockpit Analysis UI:

- `descent_page.py`
- `lattices_page.py`
- `independence_page.py`

They are intentionally not wired into primary navigation. The active specialist
pages remain in `rank42/ui_pages/` and are reachable from the unified Analyze
cockpit when explicit arithmetic or detailed inspection is needed.

Do not delete these snapshots until the Analyze cockpit has survived release
testing and the old workflows are confirmed unnecessary.
