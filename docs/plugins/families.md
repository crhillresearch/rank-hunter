## Family details

Open **Plugins → Families** in Rank Hunter for the version you actually have installed.

Each Family also keeps its own README and provenance file in the `rh-plugins` repository. Those files are the right place for:

- equations;
- paper/reference details;
- generic sections;
- exact claim boundaries;
- family-specific search notes.

The plugin version can change without a Rank Hunter core release.
